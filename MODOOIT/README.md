# GYEONGGI MATE — 기능 체험형 웹 프로토타입

경기도 외국인 유학생·외국인 주민과 한국인 주민의 언어교환, 지역생활 적응 및 커뮤니티를 결합한 창업 아이디어 데모 웹사이트입니다.

## 실행 방법

`index.html` 파일을 Chrome 또는 Edge에서 열면 됩니다. 별도 설치나 서버 없이 실행할 수 있습니다. 인터넷이 연결되어 있으면 Google Fonts가 로드되고, 오프라인에서는 기본 폰트로 표시됩니다.

## 주요 기능

- 홈: 서비스 소개, 3가지 서비스 영역, 사용자 이용 흐름
- 메이트 찾기: Language Mate / Local Mate 전환, 프로필 수정, 언어·지역·관심사에 따른 추천 점수/순서 변경
- 채팅: 예시 상대와 로컬 메시지 교환 및 자동 **시연 응답**
- 생활 커뮤니티: 카테고리별 질문 조회, 검색, 질문 작성, 답변 작성, 예시 번역, 답변 채택 **시연**
- 미션 & 리워드: 활동 기록 및 확인 체크 후 포인트 적립, 포인트 상품 교환 **시연**
- 마이페이지: 매칭 프로필 관리, 포인트 내역, 로컬 데이터 초기화

## 시연 범위와 한계

이 웹사이트는 **서버가 없는 프런트엔드 프로토타입**입니다. 프로필·질문·메시지·포인트 등은 브라우저의 `localStorage`에만 저장됩니다. 예시 메이트는 실제 회원이 아니며, 채팅은 실제 사람에게 전달되지 않습니다. 추천은 AI 모델이 아닌 **언어·관심사·지역 가중치 기반 규칙**으로 계산합니다. 미션 상대 확인, 답변 채택, 보상 및 교환도 시연용입니다. 실제 회원 인증·실시간 채팅·AI 번역·결제·기프티콘 발급은 구현되지 않았습니다.

## 실제 서비스로 확장하려면

1. 회원가입 및 신원/성인 확인, 사용자 데이터베이스, 동의·차단·신고
2. 매칭 신청/수락, 실시간 채팅 서버 및 알림
3. 다국어 Q&A 번역, 공식 정보 출처 연결, 콘텐츠 신고/운영
4. 미션 상호 인증·사기 방지와 포인트 정산 시스템
5. 개인정보 처리방침, 보안, 데이터 보존 및 운영 정책 검토

## GitHub Pages로 공개 시연하는 방법

1. GitHub 저장소를 만들고 `index.html`, `styles.css`, `app.js`를 저장소의 최상위 경로에 업로드합니다.
2. 저장소의 **Settings → Pages**에서 **Deploy from a branch**, `main` / `root`를 선택합니다.
3. 배포 주소에 접속해 화면과 반응형 동작을 확인합니다.

**주의:** 공개 배포를 해도 사용자별 데이터는 각자의 브라우저에만 저장됩니다. 서로의 질문이나 채팅이 공유되지는 않습니다. 실제 다중 사용자 서비스는 서버·DB가 필요합니다.

## 파일 구성

- `index.html` — 웹 문서 구조
- `styles.css` — 반응형 화면 스타일
- `app.js` — 화면 렌더링 및 데모 기능

저작권: 창업 아이디어 평가·시연을 위해 생성된 프로젝트 코드입니다. 예시 인물과 게시글은 허구입니다.
